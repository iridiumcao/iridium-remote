## 审查发现与修复

### 1. [P3] 自由文本错误可能包含敏感值——已应用可选加固

被审查提交中的位置：`src-tauri/src/session.rs:647–652`；其他调试日志输出点位于 `560–564` 和 `604–609`。

`detect_connection_error_message` 移除 ANSI 转义序列后，返回匹配到的整行终端文本。`handle_output` 将该文本传给 `finish_session`，后者把它存入 `snapshot.message`，再以 `info` 级别记录。应用在发布版本中启用了写入文件的 `Info` 日志（`src-tauri/src/lib.rs:614–632`）。连接被拒绝、认证失败等普通错误本身并不必然包含密码或令牌。构成凭据泄露，需要错误文本本身先包含敏感数据，且生成的日志被预期受众之外的人读取或分享。SSH 失败检测和进程退出分类的调试日志也会输出这些文本。

例如，远程 shell 就绪之前出现的终端文本 `ssh: diagnostic token=REVIEW_ONLY_MARKER` 可以匹配检测器，并将完整标记写入状态转换日志。这个构造示例仅说明文本可以传递到日志，并未证明应用正常运行会产生这样的错误、已有真实凭据泄露，或程序会自动记录保存的 SSH 密码。

已应用的加固：从上述三个日志语句中移除消息参数，在适用位置保留会话 UUID 和状态。详细错误消息仍会传递给终端和前端状态事件，但诊断日志会失去有用的错误细节。这应结合应用的日志策略权衡，不应视为紧急安全修复要求。

### 2. [P3] 调试预览可能复制终端中已显示的机密——已应用可选加固

被审查提交中的位置：`src-tauri/src/session.rs:511–520`；预览辅助函数位于 `736–748`。

每个会话的前五个输出块会被写入日志，每块包含最多 160 个字符的预览。辅助函数会移除 ANSI 序列、展开换行并截断文本，但不会对机密内容脱敏。如果启用了调试日志，且真实令牌恰好出现在这些预览内，即使未开启可选的会话录制，它也会被复制到明文日志。调试版本会同时将这些日志写入日志目录和标准输出；应用默认的发布版本配置会过滤这些调试日志。本次审查未复现包含真实机密的输出或由此导致的日志泄露。

已应用的加固：只保留输出块序号和字节数。删除预览辅助函数、预览长度常量及不再使用的导入。终端显示、输出缓存、提示符检测和可选的加密录制继续使用原始数据。这可以减少使用调试版本连接敏感会话时的意外留存，但也会失去终端预览诊断信息。
