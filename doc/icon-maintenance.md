# Application icon maintenance

`public/logo.png` is the transparent source artwork. The desktop icon files in
`src-tauri/icons`, `public/favicon.ico`, and `doc/img/logo.png` are derived from
this source. Keep the source artwork in the repository so future regeneration
does not depend on temporary attachments or generated-image storage.

## Background repair

The previous artwork contained a painted gray/white checkerboard. Although the
files used RGBA, every alpha value was 255, including all six Windows ICO
layers. Downscaling the checkerboard made the desktop icon look like a gray or
white square.

The two supplied reference images were identical, 1024 by 1024, and also fully
opaque. The built-in ImageGen tool was used to extract the logo onto real alpha
transparency. This is an AI-assisted repair, not a pixel-identical recovery of
the original design. The phoenix, circular ring, key, numeral, white eye and
key details, and silver highlights were retained; edges may differ slightly.
The selected extraction was checked on light and dark backgrounds before use.

The selected image used this prompt:

> Use case: background-extraction. Asset type: existing Iridium Remote desktop application logo, square 1024x1024 transparent PNG. Input image is the edit target. Remove ONLY the baked-in gray/white checkerboard background, including all negative spaces inside the enclosing ring, feather gaps and gaps around the key and numeral 1. Replace background pixels with real alpha transparency, never a rendered checkerboard, white square or colored backdrop. Preserve the existing logo as faithfully as possible: EXACT same centered composition, circular ring, stylized phoenix facing right, key running diagonally from lower left, numeral 1, three white round key details, white circular eye, teal-to-navy gradients and pale silver feather highlights. Keep white eye and key dots as opaque foreground details. Do not redesign, simplify, move, crop, add text, create new objects, change palette or add shadows. Clean anti-aliased edges with no checkerboard residue. True transparent alpha background.

## Regenerate desktop icons

From the repository root, in PowerShell:

```powershell
npm run tauri -- icon public/logo.png --output src-tauri/target/icon-assets
Get-ChildItem -LiteralPath src-tauri/target/icon-assets -File | Copy-Item -Destination src-tauri/icons
Copy-Item -LiteralPath src-tauri/icons/icon.ico -Destination public/favicon.ico
Copy-Item -LiteralPath public/logo.png -Destination doc/img/logo.png
npm run tauri -- build
```

The temporary output is under Cargo's ignored `target` directory. Copying only
top-level files updates the existing desktop assets without adding the mobile
assets generated by the CLI. The current `bundle.icon` configuration already
points to these files and requires no change.

Before shipping, check PNG transparency and every ICO layer (16, 24, 32, 48,
64, and 256 pixels), and preview on both light and dark backgrounds. Keep
antialiased edges; do not remove all white or gray pixels, since some belong to
the logo itself.

Install the newly built bundle to update the executable and its shortcuts.
Changing repository images cannot update an already installed application.
If a shortcut still shows the old artwork after installing the new build,
recreate the shortcut or refresh the Windows icon cache.
