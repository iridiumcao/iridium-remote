# Iridium Remote - MVP 需求说明（V1）

## 一、项目目标

开发一个运行在 Windows（未来支持跨平台）的轻量级 SSH 客户端工具，满足以下核心需求：

* 快速连接远程 Linux 服务器
* 管理多个连接配置
* 提供稳定、可用的终端体验
* 安全保存连接凭据（无需重复输入密码）

**目标原则：**

* 优先“能用”，而不是“功能齐全”
* 优先“稳定”，而不是“复杂设计”

---

## 二、技术选型（确定版）

### 前端

* React
* Tailwind CSS
* xterm.js（终端显示）

### 后端

* Tauri（Rust）
* SQLite（rusqlite）

### 系统能力

* SSH：调用系统 ssh（OpenSSH）
* 凭据管理：keyring（系统安全存储）

---

## 三、功能范围（MVP）

## 3.1 连接管理

### 功能

* 新建连接
* 编辑连接
* 删除连接
* 显示连接列表

### 数据字段

* 名称（Name）
* 主机地址（Host）
* 端口（Port，默认 22）
* 用户名（Username）

### 非目标（暂不做）

* 分组
* 标签
* 搜索

---

## 3.2 SSH 连接

### 功能

* 点击连接 → 打开终端
* 自动执行 ssh 命令连接远程主机
* 支持密码登录（第一版）

### 实现方式

* Tauri 后端启动 ssh 子进程
* 将 stdout / stderr 输出传递到前端
* 前端通过 xterm.js 渲染终端

---

## 3.3 终端功能

### 功能

* 显示 SSH 输出
* 支持用户输入命令
* 支持基本交互（回车、删除等）

### 非目标

* 多标签页
* 分屏
* 终端主题定制
* 高级快捷键

---

## 3.4 凭据管理（关键）

### 功能

* 第一次连接时输入密码
* 成功后保存凭据
* 下次连接自动使用

### 实现方式

* 使用 keyring 存储密码
* 不在 SQLite 中保存密码

### 存储规则

* service: iridium-remote
* account: username@host

---

## 3.5 本地数据存储

### SQLite 表设计（简化版）

#### connections 表

* id (primary key)
* name
* host
* port
* username
* created_at
* updated_at

---

## 四、用户流程（核心）

### 场景1：首次使用

1. 用户打开应用
2. 添加一个连接
3. 点击连接
4. 输入密码
5. 成功登录

---

### 场景2：再次连接

1. 用户点击已有连接
2. 自动读取凭据
3. 直接登录成功

---

## 五、界面结构（简化）

### 左侧

* 连接列表

### 右侧

* 终端区域（xterm.js）

### 顶部（可选）

* 新建连接按钮

---

## 六、非功能性要求

### 性能

* 启动时间 < 2 秒
* SSH连接响应快速

### 安全

* 不明文存储密码
* 使用系统凭据管理

### 稳定性

* SSH断开不崩溃
* 错误有提示

---

## 七、明确不做（防止范围膨胀）

以下功能**明确不在 MVP 中实现**：

* ❌ 指令仓库
* ❌ 批量执行
* ❌ 多用户切换
* ❌ 文件传输（SFTP）
* ❌ 云同步
* ❌ 插件系统
* ❌ 团队功能

---

## 八、完成标准（Definition of Done）

满足以下条件即视为 MVP 完成：

* 可以创建连接
* 可以点击连接并成功 SSH 登录
* 可以正常输入命令并看到输出
* 密码可以保存并自动复用
* 应用运行稳定，无明显崩溃

---

## 九、开发优先级

1. 项目初始化（Tauri + React）
2. 集成 xterm.js（静态终端）
3. 实现 ssh 子进程调用
4. 打通终端输入输出
5. 实现连接列表（SQLite）
6. 集成 keyring（凭据存储）

---
